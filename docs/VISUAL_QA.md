# Visual QA checklist

Use only the fictional contest archive. Check at 1440 px, 1024 px, and 390 px widths.

- Upload, radio, checkbox, focus, hover, disabled, error, and success states remain legible.
- The constellation path retains textual stage names; reduced-motion disables pulsing.
- The complete execution log remains expandable, keyboard reachable, and source-text free.
- Plot titles, axes, legends, hover labels, modebar icons, and annotations meet the dark tokens.
- Anonymous mode replaces titles/project names, hides open-loop text, and warns that it is not de-identification.
- Network dates remain horizontal; project lanes, dormant gaps, resumptions, and cross-links are readable.
- Summary cards navigate to each visualization without making PDF the dominant action.
- Dropdown menus and any future table/modal/tab must use the shared surface and text tokens.
- No private excerpt is visible until an explicit evidence action.
